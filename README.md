 Project Overview:

Bootstrap Café is a responsive website revamp for an existing café business. The goal of this project was to modernize the design, improve mobile responsiveness, and enhance overall user experience using the Bootstrap framework.

The original website belonged to a small British café and lacked visual appeal and responsiveness. This redesign focuses on clean layout, improved typography, and a mobile-first approach to make the site more engaging and accessible across all devices.

Features:

Fully responsive design

Mobile-first layout

Clean and modern UI

Reusable Bootstrap components

Improved navigation and readability

Technologies Used:

HTML5 – Structure and content

CSS3 – Custom styling and layout adjustments

Bootstrap – Responsive grid system, components (buttons, sections, contact form, etc.)

Netlify – Live deployment


What I Learned:

Building mobile-responsive layouts using Bootstrap

Using Bootstrap components efficiently

Improving UI/UX for real-world business websites

Deploying static websites using Netlify
